# Gemini key (optional, free tier)

1. Go to aistudio.google.com and sign in with Google.
2. Click Get API key, then Create API key. Copy it (starts with AIza).
3. LONEWOLF OS: Rig, Gemini. Paste the key, leave Model empty (uses gemini-2.5-flash) or type another model name, Save key, Test.

What it unlocks (online only)
- Ask AI panel: "Gemini in-app" option, answers inside LONEWOLF.
- Forge: "Forge with Gemini" button builds a pack from your notes in one click.

The free tier has daily limits, and Google may use free-tier inputs to improve its models. Keep private things out of it.
